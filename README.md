# Core Breach Reborn

Core Breach Reborn is an independently developed 2D action roguelite built using Godot and GDScript.

The game takes place within a computer-inspired environment, where the player acts as an antivirus system fighting increasingly dangerous threats while developing their build through weapons, software modules, items, relics, and upgrades.

The project focuses on interconnected gameplay systems, build customization, and progression-driven combat.

## Project Information

Engine: Godot

Programming Language: GDScript

Genre: 2D Action Roguelite / Bullet Heaven

Development Status: In Development

Repository Type: Public Development Showcase

## Core Gameplay Systems

### Combat and Progression

Fast-paced arena combat against increasingly dangerous enemies.

- Player experience and leveling.
- Weapon upgrades and progression.
- Weapon evolution choices that modify weapon behavior.
- Enemy encounters, including minibosses and bosses.
- Item and upgrade rewards.

### Software Module Grid

A modular build customization system built around a 6x6 installation grid.

- Install and remove software modules.
- Manage installed and uninstalled modules.
- Customize builds through module placement.
- Organize available modules using sorting controls.
- Modify gameplay and combat statistics through installed software.

### Items and Relics

Additional gameplay modifiers and progression systems that influence how each run develops.

- Collectible items with distinct gameplay effects.
- Item tiers and reward caches.
- Relics providing additional build customization.
- Interactions between combat statistics and acquired upgrades.

### Corruption System

A risk-and-reward system introducing additional decisions during gameplay.

- Corruption tracking and resistance.
- Corrupted terminals offering potentially valuable rewards.
- Permanent corruption penalties from certain interactions.
- Upgrade trade-offs that improve one statistic while reducing another.

### Weapon Evolution

Weapons can gain additional capabilities through dedicated evolution choices.

Evolution paths alter weapon behavior, offering different approaches to combat and further progression.

### System Market

An upgrade market between stages, allowing players to purchase software and other improvements.

Available upgrades cover multiple categories, including damage, defense, utility, and miscellaneous effects.

### Statistics and Run Tracking

The game includes detailed gameplay statistics and end-of-run reporting.

Tracked information includes:

- Run duration and level reached.
- Total kills and enemy categories.
- Total damage and boss damage.
- Critical hits and highest damage dealt.
- Weapon-specific performance.
- Items and relics acquired.

## Development

Core Breach Reborn is an ongoing independent development project focusing on systems-driven gameplay.

Development involves designing, integrating, testing, debugging, and expanding interconnected gameplay systems.

The project uses an AI-assisted programming workflow, with hands-on involvement in system design, implementation planning, integration, testing, debugging, and iteration.
